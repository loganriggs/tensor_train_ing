## Changes adopted
1. **One dtype policy helper.** `normalization.upcast` (promote to at least FP32, never downcast) is now the only
   way code raises precision. New code must use it rather than `.float()`. That removes the bug class above.
2. **Compute distributed references in isolation.** In multi-process tests, compute the single-process reference
   with collectives disabled (`commit(distributed=False)`, local counts), or before `init_process_group`.
   Never route the reference through the code under test's collectives.
