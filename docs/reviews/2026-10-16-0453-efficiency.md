2. **Test production shapes from the start:** kernel tests now include head dim 128. Rule: every head dim/dtype used by a
   `shapes.py` preset must appear in `tests/test_kernels.py`.
3. **Profiling:** rank individual kernels by CUDA time (as `scratch/profile_breakdown.py` now does); never infer categories from names.
4. **Corrected the previous review:** the `/workspace/.env` compile-cache setting was a no-op (non-login shells don't source it).
   I removed it. Default `/tmp` caches already give warm compiles (12 s vs 29 s cold).
5. **Coordinate checks:** use the learnable `task="repeat"` probe and ≥ 20 steps by default; random-token, 3-step probes understate alignment.
