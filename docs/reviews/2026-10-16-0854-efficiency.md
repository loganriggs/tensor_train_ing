   line). A grep watcher matched the instruction I had just written. Fix: signal by PID only (`pgrep` → check → `kill PID`),
   and make watchers match a unique token that only the other party writes.
2. **Stale frozen artifacts.** A frozen snapshot protects a run from edits, but it also freezes out fixes. Fix: before any
   multi-hour run, run a **canary** first. Compare the first ~100 post-warmup steps' tok/s to the latest matched measurement
   (now 67–68k tok/s for screen_100m), and re-snapshot right before launch.
3. **Integrating before measuring.** Prototype the timing of any performance idea in a standalone microbenchmark before
   wiring it into config, model and tests.
