## Repeated bug classes and fixes
1. **Idle GPU between sweeps (new, high cost).** Fix adopted: **always keep the next sweep chained** behind the running one
   (`runs/<exp>/chain.sh` waits on the running driver's PID, then execs the next). The ordered GPU queue now lives in
   `docs/scaling.md`, and the next item gets prepared while the current one runs.
2. **Downcasts (3rd time).** The rule didn't hold, so this is now a structural test: `test_full_analyze_runs_in_fp64` runs every
   diagnostic end to end on FP64 models (3 norm packages). It immediately exposed **12 latent downcasts** in `analysis.py`
   (local tensors, read/write graph, JVPs, quantiles, fixed denominators). All are fixed via `upcast`, and the suite now has 866 passing.
3. **Launching despite a failing preflight.** If `plan_sweep` storage exceeds free disk, fix the plan before launching. A driver
   should stop at the first admission failure instead of cycling through every candidate (it costs nothing, but it buries the real error).
