# Optimizer exposure and schedule comparison

Brief§5 requires cumulative LR and weight-decay exposure so changing training duration is not mistaken for equivalent regularization. Both trainers now checkpoint and log the ordered group totals after each successful update, before incrementing global progress counters. Resume and cooldown branches inherit these totals; an older checkpoint without them starts a clearly incomplete observed history.

For scheduled learning rates eta_t and decoupled decay coefficients lambda_t, the homogeneous shrinkage factor is P = product_t(1 - eta_t lambda_t). This follows directly from the decay term in the [AdamW update](https://docs.pytorch.org/docs/2.14/generated/torch.optim.AdamW.html). Sum(eta_t lambda_t) is useful exposure metadata, but exp(-sum(eta_t lambda_t)) only approximates P. For positive factors the implementation accumulates log1p(-eta_t lambda_t); it records sign and zero factors separately to keep JSON finite in degenerate cases.

This product describes a parameter participating in every recorded update, before floating-point rounding. It is not a model norm prediction: gradient updates also change parameters, and optimizers skip parameters whose gradients are None. The installed native Muon implementation likewise uses raw scheduled group LR for decay; its matrix-shaped Newton–Schulz update has a separate LR scaling. Both child group schedules remain distinct.

Helper tests cover analytic products, changing learning rates, interrupted accumulation, inherited history, zeros/sign changes, group mismatch, snapshot immutability and overflow rollback. Trainer tests compare cumulative sums with recorded group rates and retain exact whole/interrupted/cooldown replay. Group layout hashing uses ordered shapes/dtypes and names if available; it cannot independently identify equal-shaped swaps when names are absent. Checkpoint layout checks remain authoritative for recovery.

Evaluation reports now derive training descriptors from loaded checkpoint metadata, including cooldown horizon in serial checkpoint extra or distributed progress. Comparisons label observed dimensions matched, different or unknown. A matched target set is still a valid predictive contrast across training conditions, but it is not an automatic fair ranking. Missing historical descriptors are unknown, even when absent on both sides.
