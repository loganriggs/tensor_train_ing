## Bug classes
1. **FP32 downcast (4th time, now in a new module).** This time the FP64 test caught it **before** it shipped, because the new module's tests
   were written in FP64 from the start. That's the right outcome. Rule (now practiced, not just written): every new numeric module's
   first test runs in FP64.
2. **Layer-coupled interventions applied in parallel.** Clipping all layers from one measurement is wrong because layer i changes layer i+1's
   input. The test caught it. General lesson for any future per-layer intervention (pruning, clamping, ablation): measure and apply
   sequentially, or prove independence.
