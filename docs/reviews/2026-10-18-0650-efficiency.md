## Mistakes and fixes
1. **Liveness by pattern match, twice.** (a) 05:39: `pgrep -fc norm_canary` returned 2 (matching my own shell), so I reported a run as
   "still running" that had died at 04:23. The CPU then idled ~1.5 h on an unread result. (b) 06:45: `pkill -f` killed its own shell, losing a
   launch. **Fix:** `norm_canary.py` now writes `OUT/<norm>.done` with rc and the last row. Liveness is checked by file, never by process
   pattern. Exact-PID kills are now a memory rule.
2. **Expensive tests before cheap ones.** Three 45-min training canaries ran before a 1-min init scan showed the 10^19 per-token explosion.
   **Rule:** run `scripts/poly_init_scan.py` (init, real data, ~1 min per config) before any training canary of a new polynomial setting. Now in
   the canary's docstring.
