## Lesson: don't headline a preliminary number
At 08:50 I showed the user "~2.8× lower H100 LR" from a 3-of-4-point fit, labelled preliminary. The 4th point made the sweep flat, and the number
evaporated. It wasn't applied, but it spent user attention and nearly triggered a ~$6 experiment proposal. **Rule:** an LR optimum from a sweep is
reportable only when it is interior *and* the CE range exceeds the noise floor (`fit_lr_optimum.py` now says FLAT otherwise). Before that, report the
raw points, not a derived extrapolation. The tool enforces the second half.
